# Atrium add-on repository

The Atrium add-on for Home Assistant: your house in the Atrium app and on the web, over your tailnet, signed in
by Tailscale. Add this repository in Home Assistant (Settings → Add-ons → Add-on Store → ⋮ → Repositories):

    https://github.com/cmmichael/atrium-addon

Then install **Atrium**. See [atrium/DOCS.md](atrium/DOCS.md).

Published from the Atrium repository by `tools/publish-addon.sh`; the source of truth is there. Current version:
**0.4.0** (atrium@9709f3d).
